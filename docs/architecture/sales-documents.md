# 销售资料库

V24 提供 CRM 内部销售资料库。资料是可审计的文本内容，供销售团队维护产品说明、异议处理、话术和流程指引；它不是交付文档、合同附件或客服知识库。

资料状态为 `DRAFT -> PUBLISHED -> ARCHIVED`。创建需要 `document:manage` 与 `Idempotency-Key`；发布和归档要求 `document:manage` 与匹配的 `version`。每次状态变更写审计和 Outbox，归档资料仍可查询但不能重新发布。

本版本不提供上传、下载、二进制对象存储或外部网盘同步。此类能力必须先在平台文件域定义存储、病毒扫描、保留期限与对象权限契约，不能以临时路径或数据库 BLOB 绕过。
