# CRM 销售话术

V25 提供 CRM 内部销售话术台账。话术是按销售阶段和适用场景组织的可审计文本，供销售团队维护开场、需求澄清、异议处理和谈判指引；它不是自动外呼脚本、生成式模型提示词，也不与呼叫中心、在线客服或其他外部沟通平台同步。

## 数据与权限

`crm_sales_playbook` 保存标题、销售阶段、适用场景、文本内容、负责人、生命周期时间和乐观锁版本。租户创建时自动种子化 `playbook:read` 与 `playbook:manage`；管理员和主管拥有默认权限，其他角色须通过角色权限显式授予。

所有读写 SQL 都以 `tenant_id` 限定。创建使用 `Idempotency-Key`，同一租户和操作键重放返回初次响应且不会重复创建审计或 Outbox。发布、归档请求必须提供当前 `version`。

## 生命周期

话术状态固定为 `DRAFT -> PUBLISHED -> ARCHIVED`。只有草稿可以发布，只有已发布话术可以归档，归档后不能重新发布或修改。数据库约束保证草稿没有时间戳、已发布话术只有发布时间、已归档话术同时拥有发布时间和归档时间。

创建、发布和归档均在同一事务写不可变审计记录和 `SalesPlaybookCreated`、`SalesPlaybookPublished`、`SalesPlaybookArchived` Outbox 事件。内容作为 CRM 内部作战资料，不产生自动呼叫、消息发送或客户侧事实。
