# 交易域上下文登记

产品与价格目录已在阶段 2A 通过 V10 建表，商机管道已在阶段 2B 通过 V11 建表，报价根、版本和快照行已在阶段 2C 通过 V12 建表，审批定义及运行事实已在阶段 2D 通过 V13 建表。阶段 3 的合同、合同变更、销售订单和取消申请物理模型已在 V14 建表，来源唯一性约束在 V15/V16 固化，V17 补齐 CRM 内部生命周期、权限和关闭原因约束。阶段 4A 在 V18 增加工作台只读权限，V19 增加 CRM 销售目标和结果快照，V20 增加 CRM 绩效评分规则和结果快照，V21 增加受控连接器配置与不可变入站事件回执，V22 增加 CRM 自主获客渠道和线索归因快照，V23 增加销售会话及追加式记录，V24 增加销售文本资料库，V25 增加按销售阶段和场景维护的销售话术，V26 增加竞争对手台账；确定性报表不新增业务表。CRM 的交易边界止于销售订单，不扩展交付、回款、开票或售后域。

| 上下文 | 对象 | 主键与租户 | 跨域引用规则 |
|---|---|---|---|
| Catalog | 分类、产品、价目表、价格项已实现；折扣规则待后续迁移 | Snowflake `BIGINT`；租户表必带 `tenant_id` | 销售/交易只存 `product_id/price_list_id` 和成交快照；不 FK 到 Catalog |
| Opportunity | 商机、阶段历史、输单、重启已实现 | 聚合根和历史均 Snowflake；租户隔离 | 引用 `customer_id/contact_id/source_lead_id`；客户主数据不反向持有商机字段 |
| Quotation | 报价、报价版本、报价行和报价审批已实现 | 报价根 ID + 版本 ID；租户隔离 | 引用商机/客户/价目表；每版固化产品、价格、税率和币种快照 |
| Contract | 合同草稿、签署撤回、签署、作废和合同变更审批台账已实现 | 合同根和变更 ID；租户隔离 | 引用获批报价/客户 ID；V15 保证一个报价版本仅有一个有效合同；已签合同和订单快照不被变更审批改写 |
| Order | 销售订单草稿、确认、取消申请及审批、关闭已实现 | 订单根和行 ID；租户隔离 | 引用合同、客户、产品 ID；订单行保留商业快照。订单关闭由 CRM 销售流程显式完成，不依赖外部履约结果 |
| Analytics | 工作台销售指标、个人目标、结果确认、规则驱动计分和确定性销售报表已实现 | 目标、规则和评分均为 Snowflake ID、租户隔离 | 只读 CRM 线索、客户、商机、报价、合同和订单数据；不得接入 ERP、财务或售后事实 |
| Integration | 营销 Webhook 获客与组织 Webhook 接收回执已实现 | 连接器和事件均为 Snowflake ID、租户隔离 | 营销事件只经 Sales 公开命令创建公海线索；组织事件不写 CRM 用户、部门、角色或权限 |
| Acquisition Channel | 获客渠道与线索归因快照已实现 | 渠道与线索归因均 Snowflake ID、租户隔离 | 渠道编码在创建线索时复制；不可依赖外部平台、费用或履约事实 |
| Sales Conversation | CRM 客户销售会话和追加式沟通记录已实现 | 会话和记录均为 Snowflake ID、租户隔离 | 必须关联客户，可选联系人；不镜像呼叫中心或在线客服原始会话 |
| Sales Document | CRM 文本销售资料库已实现 | Snowflake ID、租户隔离 | 仅存文本资料及生命周期；二进制文件、外部网盘与交付附件不在该上下文 |
| Sales Playbook | CRM 销售话术已实现 | Snowflake ID、租户隔离 | 仅存销售阶段、场景、文本和生命周期；不接入自动外呼、呼叫中心或在线客服 |
| Competitor | CRM 竞争对手台账已实现 | Snowflake ID、租户隔离 | 仅存名称、定位、优势、短板和生命周期；不接入外部情报或自动分析 |

全局规则：金额 `NUMERIC(18,2)`，币种 ISO 4217，时间 UTC `TIMESTAMPTZ`；跨上下文只保存 ID，不建实体级 FK；跨域一致性依赖应用校验和 Outbox 事件。除已实现的目录、商机、报价、审批、合同和销售订单表外，禁止创建交付、收款、发票、工单等正式表，现有静态测试继续校验 `crm_delivery`、`crm_payment`、`crm_invoice` 和 `crm_ticket` 不存在。
