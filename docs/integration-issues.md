## 三、一致性自查结论（后端侧）

- 统一返回结构 `Result{code, message, data}` 全接口一致；`code=200` 成功，错误码语义见 Result.code 描述与《接口注解开发规范》。
- 分页返回统一为 `PageResult{page, size, total, pages, records}`。
- 字段命名统一下划线转驼峰（map-underscore-to-camel-case），前端按驼峰取值。
- 权限标识：登录接口免鉴权；其余接口需 `Authorization: Bearer <token>`，权限码已在接口 description 标注。
- 已知待办：@ApiResponse（业务错误码 1000+ 场景说明）按规范为增量补充项，将在联调反馈后逐接口补齐。
