# 错误码对照表

> 版本：v1.0　用途：前端、测试根据错误码直接判断问题原因，无需沟通后端。
> 来源：`com.aicrm.common.ResultCode` 枚举 + 各接口 `@ApiResponse` 标注（已随 4.1 巡检全量对齐）。
> 约定：所有接口失败时返回 `Result{code, message, data=null}`；`code=200` 成功。

## 一、通用错误码

| 错误码 | 含义 | 触发场景 | 前端处理建议 |
| --- | --- | --- | --- |
| 200 | 操作成功 | 正常返回 | — |
| 400 | 请求参数错误 | 参数缺失/格式非法/枚举非法（如状态值不在枚举内）；Spring 校验 @NotNull 失败 | 按后端返回 message 提示，修正表单 |
| 401 | 未登录或登录已过期 | 未携带 Authorization 或 token 无效/过期 | 跳转登录页，刷新 token |
| 403 | 无权限访问 | 当前用户缺少按钮权限码 | 隐藏/禁用对应入口，提示无权限 |
| 404 | 资源不存在 | 通用资源不存在（部分模块用专用码，见下） | 提示"数据不存在或已被删除" |
| 500 | 系统内部错误 | 未捕获异常 | 提示系统繁忙，上报日志 |

## 二、业务错误码（1000+）

### 租户 / 套餐（1001-1005）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1001 | 租户不存在 | 按 ID 操作租户 |
| 1002 | 租户已停用 | 登录/操作已停用租户 |
| 1003 | 租户已到期 | 过期租户登录（提示联系续费） |
| 1004 | 套餐不存在 | 按 code 查套餐 |
| 1005 | 套餐已下架 | 引用已下架套餐 |

### 用户（1101-1102）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1101 | 用户不存在 | 用户编辑/删除/重置密码/分配角色 |
| 1102 | 用户已停用 | 登录被停用账号 |

### 线索（1201-1202）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1201 | 线索不存在 | 线索详情/分配/回收 |
| 1202 | 线索状态非法 | 状态流转不在允许集合 |

### 渠道（1301-1304）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1301 | 渠道不存在 | 按 ID 引用渠道定义 |
| 1302 | 渠道账号不存在 | 账号编辑/删除/刷新 token/健康状态 |
| 1303 | 渠道事件重复 | 同一事件重复上报（当前实现返回 false 不抛错） |
| 1304 | 渠道开放平台 API 调用失败 | token 刷新/评论拉取/私信发送时三方 API 异常 |

### 会话（1401）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1401 | 会话不存在 | 会话详情/发消息/关闭/归档/转人工 |

| --- | --- | --- |

### AI（1601-1602）

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |

| --- | --- | --- |
| 1701 | 文件上传失败 | 上传写入存储失败 |
| 1702 | 文件大小超出限制 | 超出配置大小上限 |

## 三、边界场景 → 错误码对照

| 操作类型 | 边界场景 | 错误码 |
| --- | --- | --- |
| 新增 | 必填字段为空 | 400 |
| 新增 | 引用的父级/关联资源不存在（如产品分类、竞品） | 404 或对应模块码（1301/1201 等） |
| 新增 | 重复数据（如字典编码重复） | 400（唯一约束提示） |
| 编辑 | 目标记录不存在/已被删除 | 404 或专用码（1101/1302/1401 等） |
| 编辑 | 传参为空（如话术内容清空） | 400 |
| 编辑 | 状态值非法 | 400 |
| 删除 | 目标记录不存在 | 404 或专用码 |
| 删除 | 被下级/其他数据引用（如分类下有产品） | 400（业务提示"存在子级/引用，禁止删除"） |
| 批量 | 批量中单条失败 | 400（整体失败，含失败原因 message） |
| 启停/上下架 | 目标不存在 | 404 或专用码 |
| 分配/回收 | 无在线销售可分配 | 400（"无可用坐席"） |
| 转人工 | 会话不存在/已关闭 | 400/1401 |
| 登录 | 账号密码错误 | 400（"账号或密码错误"） |
| 登录 | 租户停用/到期 | 1002/1003 |
| 授权/刷新 | 渠道 token 失效 | 1304 |

## 四、使用约定

1. 前端统一在响应拦截器按 `code` 分类处理：`200` 走成功分支；`401` 跳登录；`403` 提示无权限；其余弹出 `message`。
2. 批量操作失败建议整体回滚并提示失败条数（当前批量接口为逐条校验，失败即返回首个错误）。
3. 新增业务错误码时需在本表登记，禁止复用 1000+ 已有码位。
